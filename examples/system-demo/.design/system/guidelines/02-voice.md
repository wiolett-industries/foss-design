# Voice and tone

Harbor talks like a good dispatcher: short, specific, calm.

| Instead of | Write |
| --- | --- |
| Oops! Something went wrong | Could not save the route. Try again in a minute. |
| Successfully created! | Shipment created |
| Click here | Open the manifest |

Numbers use tabular figures and the mono face in tables:

```tsx
<td className="font-mono tabular-nums">48</td>
```
